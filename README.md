# MEISEI OPS

明成社の業務ダッシュボード（macOS アプリ）の配布ページです。

赤伝処理・書類検索・見積書作成・納品明細突合・メール仕分け・業務日報など、
日々の事務作業をまとめて置いてあります。

---

## ダウンロード

**➡️ [MEISEI-OPS.dmg をダウンロード](../../releases/latest/download/MEISEI-OPS.dmg)**

このリンクは常に最新版を指します。ブックマークしても構いません。

- Apple Silicon（M1〜）／Intel の両方に対応（ユニバーサル）
- Apple の公証（notarize）済み。警告なしにそのまま開けます
- 必要な macOS: **14 (Sonoma) 以上**

## インストール

1. ダウンロードした `MEISEI-OPS.dmg` をダブルクリックして開く
2. **MEISEI OPS** のアイコンを、右の **Applications** フォルダへドラッグ
3. Launchpad か「アプリケーション」フォルダから **MEISEI OPS** を起動
4. 「ダウンロードした App です。開いてもよろしいですか?」→ **開く**
5. Google アカウントでサインイン

インストールはこれだけです。以降の更新作業は要りません（下記）。

## アップデートは自動です

**一度入れたら、あとは放っておいて大丈夫です。**

アプリが起動時と 6 時間ごとに新しい版を確認し、見つかったら自分でダウンロードして
入れ替えます。DMG を配り直したり、入れ直してもらったりする必要はありません。

- 入れ替えは**作業の邪魔にならないタイミング**（5 分以上キーボード・マウスを触っていないとき、
  または 20 時〜翌 8 時）に行われ、そのときアプリが一度だけ再起動します
- 書きかけの返信文案や、AI の応答待ちがある間は入れ替えません
- 署名・チーム ID・公証・バージョンの新しさをすべて検証してから入れ替えます。
  検証に通らなければ何もしません
- 入れ替えに失敗した場合は、元のアプリに自動で戻ります

自動更新を止めたいとき（通常は不要です）:

```sh
# 更新は確認するが、入れ替えは手動にする
defaults write jp.clearai.meisei.ops autoInstallUpdates -bool false

# 更新の確認自体をやめる
defaults write jp.clearai.meisei.ops updateEnabled -bool false
```

## サインインできる人

- **明成社の Google アカウント（@meiseicorp.co.jp）** — 全員そのまま入れます
- **個別に招待されたアカウント** — 管理者が許可リストに追加したメールアドレス

上記以外のアカウントでは、DMG をダウンロードできてもサインインできず、
中身のデータは一切見られません。

社外の方に使ってもらう場合は、管理者（clear AI）にメールアドレスを伝えて
許可リストへの追加を依頼してください。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「このアカウントではログインできません」 | 明成社のアカウントを選び直す。社外の方は許可リストへの追加を依頼 |
| Google のアカウント選択画面が出ない | ブラウザで別の Google アカウントにサインイン中の可能性。選択画面で切り替える |
| アプリが起動しない／古いままに見える | 一度アプリを終了して起動し直す。それでも直らなければ、上のリンクから最新の DMG を入れ直す |
| 「開発元を確認できません」と出る | 公証済みのため通常は出ません。出る場合はダウンロードが壊れている可能性があるので落とし直す |

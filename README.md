# MEISEI OPS — 配布物

明成社の業務ダッシュボード (macOS) の配布用リポジトリです。
アプリ本体のソースは別リポジトリ (Private) にあり、ここには配布物だけを置いています。

## ダウンロード

[Releases](../../releases/latest) から `MEISEI-OPS.dmg` を取得してください。
ユニバーサル (Apple Silicon / Intel)、Developer ID 署名 + 公証済みです。

`version.json` はアプリの自動アップデート確認用のフィードです。

## 使うには

明成社の Google アカウント (@meiseicorp.co.jp) でのサインインが必要です。
社外の人がダウンロードしても、サインインできないため中身は見られません。
